# GameView

A hockey game-review tool. Paste a YouTube game film, bookmark plays with IN / teach pause / OUT, draw stepwise mark-up, then present a short playlist.

## Use it

Open the hosted app:

https://raimondeee.github.io/GameView/

- Reviews stay in that browser’s local storage
- **Copy share link** sends another coach the full playlist (clips, pauses, drawings, steps)
- **Export JSON** / **Open playlist file** works as a backup

## Develop locally

```bash
npm install
npm run dev
```
